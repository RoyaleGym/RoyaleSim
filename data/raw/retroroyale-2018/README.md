# data/raw/retroroyale-2018

Supercell game-data tables from a ~2018 Clash Royale build, vendored from a public archive.
All content and trademarks are Supercell's; they are used here as measurement input only and
are not covered by this repository's MIT licence.

The extractors in `tools/` (`extract_arena.py`, `extract_cards.py`, `extract_globals.py`) read
this tree and write `data/derived/`; nothing else in the repo touches it.
